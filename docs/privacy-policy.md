# V-HUB プライバシーポリシー

最終更新日: 2026年5月27日

V-HUB(以下「本アプリ」)は、Kei Karino(以下「開発者」)が提供する Valorant 公式試合スケジュールの閲覧アプリです。本アプリはユーザーのプライバシーを尊重し、以下の方針に基づいて取得情報を取り扱います。

## 1. 取得する情報

本アプリは以下の情報を取得します。

- **広告識別子(IDFA / 広告 ID)**: Google AdMob によるバナー広告配信のために使用します。
- **デバイス情報**: OS バージョン、デバイスモデル、言語設定などの非個人識別情報。
- **クラッシュレポートおよび利用状況分析**: Firebase(Google LLC 提供)を通じて、アプリの安定性向上のために匿名化されたクラッシュ情報や画面遷移情報を収集する場合があります。

本アプリはユーザーアカウントを必要とせず、**氏名・メールアドレス・電話番号などの個人情報は一切収集しません**。

## 2. 端末上の機能アクセス

本アプリは、ユーザーの明示的な許可に基づき、以下の端末機能にアクセスする場合があります。これらの情報は端末内のみで使用され、開発者または第三者に送信されることはありません。

- **カレンダー / リマインダー**: ユーザーが「カレンダーに追加」操作を行った試合の予定を端末のカレンダーアプリに書き込むために使用します。
- **App Tracking Transparency (ATT)**: 広告のパーソナライズに広告識別子を使用してよいかを iOS の標準ダイアログで確認します。「許可しない」を選択された場合、非パーソナライズ広告が配信されます。

## 3. 第三者サービス

本アプリは以下の第三者サービスを利用しています。各サービスのプライバシーポリシーをご確認ください。

- **Google AdMob**: 広告配信。 [https://policies.google.com/technologies/ads](https://policies.google.com/technologies/ads)
- **Google Firebase (Firestore / Crashlytics)**: データ配信とクラッシュレポート。 [https://firebase.google.com/support/privacy](https://firebase.google.com/support/privacy)

これらのサービスは独自のプライバシーポリシーに従って情報を取り扱います。

## 4. データの保管と削除

- 本アプリ内のユーザー設定(言語選択など)は端末ローカルにのみ保存されます。
- 本アプリは個人情報を独自サーバーに保管しません。
- 広告識別子の使用停止やリセットは、iOS の **設定 → プライバシーとセキュリティ → トラッキング** および **Apple Advertising** から行えます。

## 5. 子どもの利用

本アプリは特に 13 歳未満の子どもを対象として設計されていません。13 歳未満の方は保護者の同意の上でご利用ください。

## 6. ポリシーの変更

本ポリシーは予告なく変更される場合があります。変更があった場合は本ページにて告知します。
